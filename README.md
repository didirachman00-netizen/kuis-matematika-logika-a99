# -kuis-matematika-
Tiap soal punya batas waktu 3 menit. Jawaban benar paling cepat bernilai 1.000 poin, lalu turun sedikit demi sedikit tiap detik sampai 10% (100 poin) di detik terakhir. Jawaban salah atau waktu habis = 0 poin. Maksimal 12.000 poin. Jawaban langsung terkunci saat dipilih. Satu nama hanya bisa bermain sekali.
